# Steward pilot — operational materials

The documents the pilot plan's gate list (../steward-pilot-plan.md §2) requires before
any participant is onboarded. Square-bracketed placeholders (`[OPERATOR NAME]`,
`[CONTACT]`, dates) must be filled in before use; nothing here is participant-ready
until they are.

| Doc | Gate item | Audience |
|---|---|---|
| `consent-sponsor.md` | 9 | Sponsor (participant-facing) |
| `consent-spender.md` | 9 | Spender (participant-facing) |
| `privacy-notice.md` | 9 | Both parties (participant-facing) |
| `comprehension-check.md` | 9 | Operator script |
| `onboarding-runbook.md` | 7 | Operator checklist, one copy per pair |
| `incident-protocol.md` | 9 | Operator |
| `loop-harness-design.md` | 3 | Engineering |

Participant-facing documents are written to be readable without a technical or legal
background; keep them that way when editing. The two consent forms are deliberately
separate documents delivered in separate conversations — see plan §4.
